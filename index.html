    🔔 Notification System - എങ്ങനെ Work ആവും?

    1. Link ഉള്ളവർക്ക് (Browser Notification - App പോലെ):
    • ഈ link open ചെയ്ത് 🔔 Allow ചെയ്യുന്ന എല്ലാവർക്കും
    • Phone-ൽ App notification പോലെ വരും, Chrome/Safari background-ൽ ആണെങ്കിലും
    • Winner ആയാൽ, പുതിയ member ചേർത്താൽ, payment ആയാൽ auto notification

    2. WhatsApp Group-ന്:
    • Admin winner save ചെയ്യുമ്പോൾ auto WhatsApp group-ൽ message പോകാൻ button
    • Settings-ൽ WhatsApp Group Link save ചെയ്യൂ
    • പുതിയ winner: "🎉 Kuri 1 Winner: Ramesh - 20-01-2026" എന്ന് group-ൽ പോകും

    3. SMS ആയി (Optional - Paid):
    • Fast2SMS / Twilio വഴി SMS അയക്കാം - ഒരു SMS-ന് ₹0.15-0.30
    • എല്ലാ member-ന്റെ phone-ലേക്കും SMS പോകും

    4. App ആക്കിയാൽ (Best):
    • ഈ HTML-നെ PWA ആക്കി Home Screen-ൽ Add ചെയ്താൽ 100% App പോലെ notification
    • അല്ലെങ്കിൽ APK ആക്കി Play Store ഇല്ലാതെ install ചെയ്യിക്കാം - Firebase Push Notification
